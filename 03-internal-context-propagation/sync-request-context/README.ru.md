# Контекст синхронного запроса

[English](README.md) | [Русский](README.ru.md)

Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

Из этого каталога запустите сервер, затем запросите `/sync` в другом терминале:

```sh
go run .
```

```sh
curl -i http://localhost:8080/sync
```

В Windows PowerShell используйте `curl.exe`. Ответ — `sync ok`.
Внутри HTTP-спана вложены `handler.sync`, затем `service.process` и `repo.save`.
Все четыре имеют общий TraceID. У сервисного спана есть `flow.type=sync`.

Каждая функция получает контекст вызывающего кода, а потомку передаёт контекст,
который вернул `tracer.Start`. Замена на `context.Background()` разорвала бы цепочку.
Это исходный корректный пример для сравнения с [фоновой работой](../detached-background-context/README.ru.md).
