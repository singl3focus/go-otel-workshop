# Прогрев кэша со спаном на воркер

[English](README.md) | [Русский](README.ru.md)

Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

## Запуск

```sh
go run .
```

## Ожидаемая трасса

Четыре воркера читают 200 ключей из общего канала. В одной трассе пять спанов: `cache.warmup` и четыре дочерних `cache.worker`. Воркеры перекрываются по времени; у каждого есть `worker.id`, `worker.warmed`, `worker.miss`.

Детерминированное правило примера — `len(key)%10 != 0`: все сгенерированные ключи проходят, поэтому итог `keys.warmed=200`, `keys.miss=0`. Это не случайная имитация 10% промахов. Измените правило для изучения miss events. Общий родительский контекст безопасен: `wg.Wait()` удерживает прогон до завершения воркеров.

Спаны выводятся через batch exporter stdout. Дождитесь задержки экспорта
или штатного завершения процесса. См. [все примеры джобов](../README.ru.md).
