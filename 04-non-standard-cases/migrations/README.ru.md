## Запуск

```sh

```

## Ожидаемая трасса

Три имитируемые SQL-миграции выполняются последовательно. В одной трассе четыре спана: `migrations.run` и три дочерних `migration.apply`. У корня — `db.system=postgres`, `migrations.total=3`, `migrations.applied=3`; у потомков — `migration.name`.

При ошибке корень сохраняет число применённых миграций. Штатный статус — Unset. Ошибка записывается на упавшем потомке и корне. Shutdown выгружает batch processor до завершения короткого CLI.

Спаны выводятся через batch exporter stdout. Дождитесь задержки экспорта
или штатного завершения процесса. См. [все примеры джобов](../README.ru.md).
