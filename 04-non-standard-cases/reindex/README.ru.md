## Запуск

```sh
go run .
```

## Ожидаемая трасса

Пятьсот имитируемых документов обрабатываются пятью батчами по 100. В одной трассе шесть спанов: `reindex.run` и пять дочерних `reindex.batch`. Спан на каждый документ не создаётся.

Документы с индексами 0, 137, 274 и 411 дают события `doc.failed` с `doc.id` и `reason=validation`. Итоги корня: `reindex.indexed=496`, `reindex.failed=4`. Имитируемая операция батча завершается, поэтому её статус остаётся Unset при отдельных ошибочных документах.

Спаны выводятся через batch exporter stdout. Дождитесь задержки экспорта
или штатного завершения процесса. См. [все примеры джобов](../README.ru.md).
