## Ожидаемая трасса

Процесс выполняет первый тик сразу, затем каждые две секунды. У каждого тика новый корневой TraceID. Внутри `reconcile.tick` находятся два `reconcile.fetch_page` и шесть `reconcile.one`: это непосредственные потомки корня, а не вложенные друг в друга спаны.

Каждый запуск записывает `job.name`, `job.page_size`, `reconcile.processed=6`, `reconcile.failed=0`. Контекст запуска ограничен 1,5 секунды, но имитируемые sleep не учитывают отмену. Ctrl+C останавливает цикл через обработку сигнала и выгружает очередь спанов.

Спаны выводятся через batch exporter stdout. Дождитесь задержки экспорта
или штатного завершения процесса. См. [все примеры джобов](../README.ru.md).
