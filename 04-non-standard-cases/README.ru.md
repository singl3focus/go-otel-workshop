# 04 · Джобы, батчи и CLI

[English](README.md) | [Русский](README.ru.md)

Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

Четыре готовые демонстрации создают трассы без входящего HTTP-запроса.
Общий [helper stdout-экспорта](helper.go) используется с выгрузкой при штатном выходе.

| Сценарий | Граница трассы | Агрегаты |
| --- | --- | --- |
| [migrations](migrations/README.ru.md) | Корень на прогон, потомок на миграцию | Число применённых и всех миграций |
| [batch-reconciliation](batch-reconciliation/README.ru.md) | Новый корень на каждый тик | Число обработанных и ошибочных элементов |
| [reindex](reindex/README.ru.md) | Корень на прогон, потомок на батч документов | Успешные/ошибочные документы и события ошибок |
| [cache-warmup](cache-warmup/README.ru.md) | Корень на прогон, потомок на воркер | Прогретые/отсутствующие ключи |

Из этого каталога:

```sh
go run ./migrations
```

Граница трассы должна описывать конечную операцию. Спаны на батч или воркер
позволяют избежать спана на каждый элемент. После работы выгружайте экспортёр
через shutdown с ограниченным временем. `RecordError` добавляет событие
исключения, а `SetStatus(codes.Error, ...)` отдельно задаёт статус ошибки.

Имитируемые задержки используют `time.Sleep`: наличие таймаута не прерывает sleep.
Передавайте контекст реальным downstream-клиентам и проверяйте отмену в циклах.
Примеры показывают границы инструментации, а не полноценный отказоустойчивый
планировщик задач.
