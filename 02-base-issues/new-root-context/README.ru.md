# Упражнение · Потерянный родительский контекст

[English](README.md) | [Русский](README.ru.md)

Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

## Наблюдение

```sh
go run .
```

HTTP-демонстрация слушает порт 8080. Запросите `/orders`: бизнес-операция заменяет входящий контекст и создаёт отдельную трассу.

В другом терминале: `curl -i http://localhost:8080/orders` (`curl.exe` в Windows PowerShell).

## Исправление

Измените `CreateOrder` в [exercise.go](exercise.go). Сохраните входящий контекст в `CreateOrder`, а полученный контекст передайте в `saveOrder`. Все три спана теста должны иметь общий TraceID и правильную связь с родителем.

```sh
go test .
go test -tags=solution .
```

Первая команда проверяет ваш ответ и изначально падает. Вторая выбирает
[эталон](solution.go), сохраняя вашу работу. Оставьте сломанную
[демонстрацию](problem.go) для сравнения.
Вернуться ко [всем упражнениям](../README.ru.md).
