# Упражнение · Изменения после End

[English](README.md) | [Русский](README.ru.md)

Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

## Наблюдение

```sh
go run .
```

Сохраняются `phase=before-end` и Ok; `phase=after-end`, `late-event` и поздний Error не меняют завершённый спан.

## Исправление

Измените `DoWork` в [exercise.go](exercise.go). Запишите `result=success` и статус Ok, пока спан записывается, затем завершите его. Тест проверяет итоговое состояние.

```sh
go test .
go test -tags=solution .
```

Первая команда проверяет ваш ответ и изначально падает. Вторая выбирает
[эталон](solution.go), сохраняя вашу работу. Оставьте сломанную
[демонстрацию](problem.go) для сравнения.
Вернуться ко [всем упражнениям](../README.ru.md).
