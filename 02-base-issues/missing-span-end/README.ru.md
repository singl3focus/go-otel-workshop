Английская версия — оригинал. Русский перевод поддерживается рядом с ней.

## Наблюдение

```sh
go run .
```

Экспортируется только `good.span`: для `broken.span` не вызван End. Shutdown провайдера не завершает открытые спаны.

## Исправление

Измените `DoWork` в [exercise.go](exercise.go). Завершите `demo.operation`, сохранив атрибут `demo=exercise`. Тест должен увидеть ровно один завершённый спан.

```sh
go test .
go test -tags=solution .
```

Первая команда проверяет ваш ответ и изначально падает. Вторая выбирает
[эталон](solution.go), сохраняя вашу работу. Оставьте сломанную
[демонстрацию](problem.go) для сравнения.
Вернуться ко [всем упражнениям](../README.ru.md).
